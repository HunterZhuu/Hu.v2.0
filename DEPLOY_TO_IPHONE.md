# 📱 Deploy PipDuel to Your iPhone - Step by Step

## ⚡ Super Simple Method (2 minutes)

### 1. Open Terminal
```bash
cd /path/to/your/pipduel-project
```

### 2. Install Vercel (if not installed)
```bash
npm install -g vercel
```

### 3. Deploy
```bash
vercel
```

**That's it!** Vercel will ask you a few questions:
- Set up and deploy? **Y**
- Which scope? **(select your account)**
- Link to existing project? **N**
- What's your project's name? **pipduel**
- In which directory is your code? **./**
- Want to override the settings? **N**

Wait ~30 seconds and you'll get a URL like:
```
🔍  Inspect: https://vercel.com/yourusername/pipduel
✅  Production: https://pipduel.vercel.app
```

### 4. Open on iPhone
1. Open **Safari** on your iPhone
2. Go to: `https://pipduel.vercel.app`
4. Tap **"Add to Home Screen"**
6. Tap **"Add"**

**Done!** PipDuel is now on your iPhone like a real app! 🎊

## 🆘 Troubleshooting

### "Add to Home Screen" not showing?
- Use **Safari** (not Chrome)
- Make sure URL starts with `https://`
- Clear Safari cache and retry

### App looks weird?
- Rotate phone to portrait
- Close and reopen app
- Remove and reinstall

### Slow loading?
- Check internet connection
- Close other apps
- Restart phone
