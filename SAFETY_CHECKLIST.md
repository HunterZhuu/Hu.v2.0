# 🛡️ Pre-Engagement Safety Checklist

## ⚠️ CRITICAL: Complete This Checklist BEFORE Sharing Any Project Details

---

## Phase 1: Business Entity Setup ✅

### Before ANYTHING Else
- [ ] **Form your business entity** (LLC or Corporation)
- [ ] **Get your EIN** from IRS (free)
- [ ] **Open business bank account**
- [ ] **Get business license** (if required in your state)

**Why?** You need a legal entity to own the IP and sign contracts.

**Cost:** $50-500 depending on state
**Time:** 1-2 weeks

---

## Phase 2: Legal Documents Preparation ✅

### Have Attorney Prepare/Review
- [ ] **IP Assignment Agreement** - Transfers all IP to your company
- [ ] **Non-Disclosure Agreement (NDA)** - Protects confidential information
- [ ] **Independent Contractor Agreement** - Sets terms of engagement
- [ ] **Review all documents** with qualified attorney

**Why?** These documents must be legally enforceable in your jurisdiction.

**Cost:** $800-2,500 for attorney review
**Time:** 1-2 weeks

**⚠️ DO NOT SKIP THIS STEP ⚠️**

---

## Phase 3: Pre-Contact Checklist ✅

### Before Contacting ANY Contributor

**Legal Documents Ready:**
- [ ] IP Assignment Agreement (signed by you)
- [ ] NDA (signed by you)
- [ ] Contractor Agreement (signed by you)
- [ ] All documents reviewed by attorney

**Business Setup Complete:**
- [ ] Business entity formed
- [ ] EIN obtained
- [ ] Business bank account opened
- [ ] Business insurance (if applicable)

**Process Ready:**
- [ ] Onboarding checklist created
- [ ] Document storage system set up
- [ ] Code repository created with access controls
- [ ] Communication channels established

---

## Phase 4: Initial Contact Protocol ✅

### Step 1: Send NDA FIRST
- [ ] Send NDA to potential contributor
- [ ] Get signed NDA back BEFORE discussing project
- [ ] File signed NDA securely

**⚠️ NEVER share project details before NDA is signed ⚠️**

### Step 2: High-Level Overview Only
- [ ] Share only high-level concept (e.g., "trading platform")
- [ ] Do NOT share technical details
- [ ] Do NOT share business model details
- [ ] Do NOT share financial projections
- [ ] Do NOT share source code

### Step 3: Formal Engagement
- [ ] Send Independent Contractor Agreement
- [ ] Send IP Assignment Agreement
- [ ] Get BOTH signed BEFORE any work begins
- [ ] File all signed documents securely

**⚠️ NEVER start work before all documents are signed ⚠️**

---

## Phase 5: Due Diligence ✅

### Before Hiring Anyone

**Identity Verification:**
- [ ] Verify their identity (LinkedIn, portfolio, etc.)
- [ ] Check references (minimum 2-3)
- [ ] Review past work/portfolio
- [ ] Check online reputation

**Conflict Check:**
- [ ] Verify they're not employed by competitor
- [ ] Verify they don't have conflicting IP obligations
- [ ] Verify they're not working on similar project
- [ ] Check for any potential conflicts

**Capability Check:**
- [ ] Verify technical capabilities
- [ ] Review relevant experience
- [ ] Assess communication skills
- [ ] Check availability and timeline

**Red Flags - Walk Away If:**
- [ ] ❌ Refuses to sign IP Assignment
- [ ] ❌ Refuses to sign NDA
- [ ] ❌ Wants to retain IP rights
- [ ] ❌ Has existing IP conflicts
- [ ] ❌ Poor communication
- [ ] ❌ No references or portfolio
- [ ] ❌ Pressure tactics

---

## Phase 6: Onboarding Process ✅

### When Hiring Someone

**Day 1: Documents**
- [ ] Send NDA (if not already signed)
- [ ] Get signed NDA
- [ ] Send Contractor Agreement
- [ ] Send IP Assignment Agreement
- [ ] Get both signed
- [ ] File all documents securely

**Day 2: Access Setup**
- [ ] Create limited access accounts
- [ ] Grant minimum necessary permissions
- [ ] Set up project management access
- [ ] Set up communication channels

**Day 3: Project Briefing**
- [ ] Share project overview
- [ ] Share technical requirements
- [ ] Share timeline and milestones
- [ ] Share communication expectations

**Day 4-7: Work Begins**
- [ ] Monitor work quality
- [ ] Regular check-ins
- [ ] Document all contributions
- [ ] Keep audit trail

---

## Phase 7: Ongoing Management ✅

### During Engagement

**Weekly:**
- [ ] Review work quality
- [ ] Check compliance with agreements
- [ ] Address any issues immediately
- [ ] Document progress

**Monthly:**
- [ ] Review all contributions
- [ ] Update documentation
- [ ] Process payments on time
- [ ] Address any concerns

**Ongoing:**
- [ ] Maintain audit trail
- [ ] Monitor access logs
- [ ] Regular security reviews
- [ ] Keep communication professional

---

## Phase 8: Project Completion ✅

### When Engagement Ends

**Final Deliverables:**
- [ ] Review all deliverables
- [ ] Accept or reject based on criteria
- [ ] Process final payment
- [ ] Get confirmation of completion

**Access Revocation:**
- [ ] Revoke all system access
- [ ] Revoke code repository access
- [ ] Revoke communication channel access
- [ ] Collect all company property

**IP Confirmation:**
- [ ] Get confirmation all work delivered
- [ ] Get confirmation all IP returned/destroyed
- [ ] Verify no copies retained
- [ ] File all documentation

**Relationship Closure:**
- [ ] Send thank you note
- [ ] Request feedback
- [ ] Keep door open for future work (if appropriate)
- [ ] Maintain professional relationship

---

## 🚨 Critical Red Flags - Walk Away Immediately

### Legal Red Flags
- ❌ **Refuses to sign IP Assignment** - Non-negotiable
- ❌ **Refuses to sign NDA** - Shows lack of professionalism
- ❌ **Wants to retain IP rights** - Defeats the purpose
- ❌ **Has existing IP conflicts** - Potential legal issues
- ❌ **Asks for equity instead of payment** - Be very careful

### Behavioral Red Flags
- ❌ **Poor communication** - Future problems likely
- ❌ **Pressure tactics** - "Sign now or lose the deal"
- ❌ **Unusually cheap** - May be inexperienced or desperate
- ❌ **Unusually expensive** - May be overcharging
- ❌ **No references or portfolio** - May be inexperienced

### Technical Red Flags
- ❌ **Cannot demonstrate capabilities** - May not be qualified
- ❌ **Poor code quality** - Will cause problems later
- ❌ **Misses deadlines** - Unreliable
- ❌ **Doesn't follow specifications** - Won't deliver what you need
